# ☕ Coffee Shop Sales Excel Dashboard

## 📊 Overview

This project showcases an interactive Excel dashboard built to analyze and visualize coffee shop sales data. It provides a clear understanding of sales trends, product performance, and store-wise insights using dynamic charts and filters.

## 🚀 Features

* Total Sales, Transactions, and Average Sales summary
* Monthly Sales Trend visualization
* Sales by Product Category (Coffee, Tea, Bakery, etc.)
* Store Location-wise Sales & Transactions
* Interactive slicers for filtering (Month, Product Category, Store Location)

---

## 🛠️ Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers & Data Visualization

---

## 📈 Key Insights

* Coffee is the highest revenue-generating category
* Sales show consistent growth over months
* Hell’s Kitchen and Astoria stores perform strongly
* Seasonal trends can be observed in monthly data

---

---

## 🎯 Purpose

The goal of this project is to demonstrate data analysis and visualization skills using Excel and to derive meaningful business insights from raw data.
